# 断誓之下 · BELOW THE OATH

原创的三层俯视角动作肉鸽射击游戏。NDS 风格的低多边形角色、手绘像素纹理与高分辨率实时光影结合。项目包含可运行的源代码与生产构建，地牢模型、纹理、特效与战斗音效由本项目代码生成，主菜单为代码生成的 Three.js 动态黑铁档案厅。配乐使用 Scott Buckley 的 CC BY 4.0 作品，人物台词为预先制作的中文合成语音；来源、授权与改编说明保存在 `public/audio-credits.html` 和 `public/audio/music-manifest.json`。游戏运行时素材均本地加载，无需远程素材或语音服务。

## 启动

Windows 双击 `start-game.cmd`，默认在 5188 端口启动正式版并打开浏览器。启动器会检测源代码是否比构建更新，需要时重新构建，并使用包含构建编号的新地址打开页面。运行生产构建只需要 Node.js；首次从源代码构建需要安装依赖。

```powershell
npm install
npm run dev
```

浏览器打开 **http://127.0.0.1:5187**。电脑使用键鼠；手机和平板使用双摇杆与独立按钮，只支持横屏游玩，竖屏会暂停并提示旋转。声音会在首次点击后启用，可在标题画面或暂停菜单切换。

生产构建与独立服务：

```powershell
npm run build
node server.mjs
```

正式版默认地址为 **http://127.0.0.1:5188**，开发版仍使用 5187。如果 5188 被其他项目占用，可用 `node server.mjs --port 5189` 或 `powershell -File start-game.ps1 -Port 5189` 指定端口。

## 电脑、手机与平板

电脑继续双击 `start-game.cmd`，使用 5188 入口。手机和平板测试请双击 **`start-mobile.cmd`**：它构建最新版并启动 5189 局域网服务，窗口会显示这台电脑的 Wi-Fi 地址。设备连接同一 Wi-Fi 后，用手机 / 平板浏览器打开该地址并横向握持。`127.0.0.1` 仅用于电脑自身，手机需要使用电脑的局域网 IP。若无法连接，请允许 Windows 防火墙中的 Node.js 在专用网络通信。

也可手动运行 `node server.mjs --port 5189 --host 0.0.0.0`。独立服务器默认监听局域网；仅供本机时可加 `--host 127.0.0.1`。无需安装手机应用。

标题、职业档案、HUD、行动手册、装备详情、地图与结算均已适配横屏手机和平板，考虑屏幕安全区；按钮至少 44px，长面板可触摸滚动。保留整房间视角，手机场景目标放大约 18%，宽房间自适应限制。实际分辨率、阴影与特效密度由设置中的真实画质决定。

翻滚持续 **0.48 秒**，期间无敌，完整距离 **4.2 单位**。人物收枪并绕躯干中心旋转，路径分段检查碰撞，遇到墙体或掩体停止前进；过窄的位置无法开始翻滚。枪械有无限备用弹药，但必须装填。法杖消耗法力并用 R 凝聚，重刃无需弹药或换弹。角色受伤后有短暂保护，护盾优先承担伤害。弹壳、生命与钥匙靠近后自动拾取；武器、遗物和装置使用 E。

主菜单先显示轻量壳与背景图片，完整 3D 按需加载。确认职业开始深入和进入第二层时，独立播放约 **3 秒**的入场演出：房间浮现、镜头下降、巡火者落地、尘屑扩散、楼层标题与 HUD 出现。入场期间战斗暂停，可以按 Space、Enter、Esc 或点击场景跳过。

游戏采用展示完整房间的远景镜头，四周保留观察空间，门口、掩体和敌人分布可以同时看见。镜头根据房间尺寸与窗口比例适配，在窄屏中也完整容纳房间；角色移动仅带来轻微的镜头跟随。鼠标瞄准与镜头保持一致。

房间外围是随房间种子生成的地下遗迹与深渊：承重石基、残墙断拱、破损桥面、铜管阀门、垂落铁链和远处灯火，分布在不同深度，薄雾与尘屑缓慢移动。第一层是铜管、断桥和军械残墙；第二层使用独立的下沉葬室、石棺、骸骨壁龛、拱门、墓灯和深井雾气。外围景观亮度低于战斗区域，实际房间出口仍由带红绿通行灯的石门标识。

已打开的旧标签页会保留原来加载的脚本，重新构建不能直接改变该标签页。正式服务的页面与脚本禁止缓存；`/version.json` 提供当前构建对应的加载地址，启动器自动使用这个地址。

房门采用厚重石框、铜制栅闸和雕刻门楣。绿灯、地面箭头和“可通行”标牌表示开放；红灯与“战斗封锁”标牌表示封锁。清场后闸门收起，升起完成后才允许穿过。

主角采用 **余烬枪侠** 造型：宽檐战帽、鲜红围巾、破边短披风、铜黑护甲、斜挂弹带、半面护具与分节护胫。主角的体量、肩部轮廓和红色布料比 NPC 更突出。持枪手向前托住武器，另一只手参与换弹。披风是可变形的布料表面：肩部固定，待机时下摆轻摆，移动时向后扬起，转向带延迟拖曳，停下后缓慢回落；围巾也随动作摆动。翻滚时收枪、收身并压低布料，整个模型逐帧检查离地高度。腰侧弹药包避开披风区域。八把武器的枪口闪光与弹道高度使用实际枪管位置。

NPC 使用五种有头部、脸部和独立四肢的地牢冒险者造型：守夜者提灯、商人背包、铸枪师穿围裙并持锤、受困巡火者带绷带与挎包、试炼引路人持铜杖。它们会转向靠近的玩家、呼吸、眨眼，并在交互时点头或抬手回应。姓名标牌只在靠近或交谈时显示；E 提示位于头部上方。对话、交易、补给和试炼仍由对应的实际事件驱动。

主菜单使用原创的军械铭文视觉：宋体中文双字标题、铜红金边按钮、弹膛徽记和暗色边框；没有使用组件库、CSS 框架或默认 UI 皮肤。

## 房间的实际轮廓

三层使用 **18 类地板轮廓**。第三层增加日冕切角殿、赤祭巡礼廊、十字审判殿、阶列祷室、环日深井和双井献祭场。第一层保留六类军械房：回廊、切角祭厅、十字厅、侧翼铸坊、两翼展廊和中央深井。第二层另有六类墓陵结构：折角墓室、亡者长廊、双列骨窟、狭窄十字墓道、错落葬室、带两座实体深井与中央通路的双井冥殿。第二层使用独立的石板纹理、骨墙壁龛、石棺障碍、墓灯与墓铭，没有军械地毯和钟盘地徽。

地板、基座和墙体都沿真实多边形生成。角色和敌人不能走入凹口外侧或中央深井；子弹可飞越低矮的坑沿，并在切角墙上按法线反弹。道具掉落会寻找可达地面，隐藏门位于有效墙段。所有房间保留与地牢图一致的门连接。

## 三层完整流程

**第一层 · 旧军械圣殿**：随机生成 11–14 个普通房间和 1 个隐藏房间。落点免费宝箱保证提供新武器与被动遗物。探索随机分支和环路，清除战斗房，寻找宝箱、铜币商店、余火神龛和漂泊者事件。随机 Boss 房中出现 **断誓钟卫**，必须击败它才能解锁深层升降井。钟卫倒下后恢复 2 格生命，奖励钥匙、职业专属武器、被动遗物与弹壳；点亮技能强化祭坛，提供第一次职业分支选择；本局继续。

**第二层 · 地下墓陵**：重新随机生成 13–16 个普通房间和 1 个隐藏房间。六类骸骨敌人使用弩手、三连弩手、亡灵咒师、骨翼蝠、骨犬和骸骨弩台的独立模型，生命和组合难度提高。墓道与石棺改变走位和射击路线；诅咒符文先闪烁 0.85 秒，再爆发 0.5 秒，翻滚无敌可避开伤害。用 E 打开石棺，可能获得陪葬奖励，也可能唤醒亡者并封锁房门。进入时恢复 3 格生命，获得钥匙与空包弹；职业和构筑保留。在随机房间位置寻找 **大司铳的葬殿**，击败三阶段大司铳后获得第二次技能强化与战利品，解锁本层升降机，继续深入黑日圣坛。

**第三层 · 黑日圣坛**：必经的最终楼层，随机生成 15–18 个普通房间与 1 个隐藏房间。黑石与暗金建筑、黑日圆盘、六类裁决军团模型和独立配乐形成新环境。光照周期明暗交替；赤祭符文先预警 1.1 秒，再爆发 0.9 秒，翻滚与无敌能避开伤害。挑战 2100 生命的 **黑日裁决者**：日冕守势、赤祭巡礼、黑日终审三个阶段，使用缺口环弹、金圈爆发、预警光束与裁决援军。击败后结束本局，结算显示 3/3 守关者。

三层各有一个随机 Boss 房；前两层各有本层 Boss 封印的升降机，击败后红灯变绿灯。提前交互无法绕过守关战。Boss 房可以位于支路或环路。新局使用浏览器加密随机种子；同一地图种子可复现连接结构。最高击杀保存在本地浏览器。

## 内容与交互

- **25 种武器**：新增日蚀三响、审判贯钉、赤祭榴铳、黑日星核、祭光权杖、血霜圣典、蚀日环刃、赤祭长枪、终审巨槌；原有装备为射手 8 把枪械（余烬六响、告解霰弹、蜂群打字机、圣葬礼炮、光棱审判、霜钟、回声星环、断罪长钉），法师 4 件法器（霜灯法杖、雷纹枝杖、焰契古卷、幽月星仪），战士 4 件兵器（赤铜重刃、断誓战斧、铜鸣战戟、熔炉震地锤）；共 22 件可掉落武器分属三个职业奖励池。
- **13 件被动遗物**：新增黑日透镜、祭血刻印、黄昏沙漏，保留伤害、弹匣、移动与翻滚、吸血、反弹、暴击、护盾、焰尾、货币与生命构筑。
- **3 个职业技能、9 条强化分支、各两阶**：前两位 Boss 后通过祭坛选择。第二次可升级同一分支至 II 阶，或转为其他分支 I 阶；每次选择重置技能冷却，本局内保留，新局重置。
